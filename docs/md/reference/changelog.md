# Changelog

All notable changes to Text 2 Image will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-17

### Added
- **Initial release of Text 2 Image** - A cross-platform command-line utility for rendering wrapped text into images.
- **ANSI Style Support** - Support for colors, bold, and italic styles using standard ANSI escape codes.
- **Word Wrapping** - Automatic text wrapping to a specified width.
- **Multi-page Output** - Support for multi-page images when a fixed height is provided.
- **Cross-platform support** - Built and distributed for Windows, Linux, and macOS.
- **Font Discovery** - Automatic font detection on Windows, Linux, and macOS.
- **Customization** - Options for padding, font size, tab size, and custom colors.
