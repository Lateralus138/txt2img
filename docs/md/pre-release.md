# Pre-Release Information

## Upcoming Release: v1.1.0 (Planned)

### Status
**Currently in Development** - Target release: Q3 2026

### Planned Features
- **PDF Export**
  - Option to output to PDF instead of PNG
- **Custom Backgrounds**
  - Use images or gradients as backgrounds
- **Additional Font Support**
  - Better handling of font weight variants and fallback fonts
- **Enhanced ANSI Support**
  - Support for 256-color and true-color (RGB) ANSI sequences (currently limited)
